# Referência do login

Foi realizada análise estática real pelo REA/JADX do APK fornecido: pacote com.netflix.mediaclient, versão 9.87.1, SHA-256 b82d572c0b0b1f9f42ef0ab7f1afdee4465b9e88c00b30b6db79b671d4ca6b60. Cinco consultas REA de classes, navegação e AccountActivity foram concluídas.

Os recursos contêm os textos em português de entrada, e-mail/telefone, senha e recuperação. Isso sustenta as funções da interface independente, mas não comprova geometria, cores ou execução da tela original. A página pública https://www.netflix.com/br/ serviu como referência visual de contraste, tipografia e composição.

A implementação usa código próprio, marca Cinema, autenticação própria no Supabase e conteúdo demonstrativo autorizado. Não usa credenciais ou backend da Netflix. O APK e recursos proprietários não foram publicados neste repositório. As evidências completas permanecem na investigação local.
