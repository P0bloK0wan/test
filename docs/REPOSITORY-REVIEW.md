# Avaliação dos três repositórios sugeridos

Inspeção estática em 2026-10-17. Os repositórios foram clonados para estudo; nenhum script, instalação ou serviço desses projetos foi executado. Nenhum código ou asset foi incorporado ao Streamlab nesta avaliação.

| Projeto / commit | Observado | Decisão |
| --- | --- | --- |
| [TheusN/superflix](https://github.com/TheusN/superflix) / 5404543b7ffaddc18c9827b7dc0dea75fd39816a | LICENSE MIT, Next.js 16/React 19, hls.js listado, catálogo TMDB, calendário, temporadas. VideoPlayer.tsx incorpora player externo por iframe; caminhos de proxy e fontes de vídeo de terceiros existem. | Melhor referência de arquitetura e funcionalidades; reaproveitamento de código exige preservar aviso MIT. Não é substituto direto para o frontend estático do GitHub Pages: rotas de servidor Next necessitam hospedagem compatível. Não adotar fontes de reprodução sem autorização demonstrada nem mecanismos de contorno de bloqueios. |
| [LuiFeAn/netflix-web-api](https://github.com/LuiFeAn/netflix-web-api) / cbcf344852675c09c3924789e2b5f93f32d93a38 | NestJS/Puppeteer. puppeteer-service.ts recebe e-mail/senha e automatiza login no site Netflix; movie.service.ts coleta dados de páginas. Badge README diz MIT, mas não há LICENSE e package.json declara UNLICENSED. | Não é API oficial nem fornece hospedagem de filmes. Não integrar coleta autenticada ou reutilizar código sem licença esclarecida. Preferir integração TMDB oficial já existente no backend. |
| [sunpills/clonenetflix](https://github.com/sunpills/clonenetflix) / 11e133c72b1ba1be684b1420332eaa0c126c682e | React 17/react-scripts 5, catálogo e imagens TMDB, componentes FeaturedMovie/MovieRow, marca Netflix externa. Nenhuma LICENSE explícita encontrada. | Referência conceitual de fileiras e destaque; não copiar código/assets sem licença/autorização. Não fornece backend, player próprio nem catálogo de arquivos de vídeo. |

A licença do software não concede direitos sobre filmes, marcas ou imagens de terceiros. TMDB fornece metadados e imagens sob seus termos; não fornece os arquivos completos para reprodução. O Streamlab mantém marca própria, autenticação/RLS no Supabase e player HTML5 próprio para arquivos autorizados compatíveis. HLS adaptativo poderá ser adicionado quando houver hospedagem que gere manifests e segmentos; apenas adicionar hls.js não converte arquivos nem resolve o player incorporado do Google Drive.
